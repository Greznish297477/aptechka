# Срок лекарств (MedExpiry)

Красивое Android-приложение для отслеживания сроков годности лекарств с автоматическим поиском картинок и уведомлениями.

## Возможности

- ✅ Добавление / редактирование / удаление лекарств
- ✅ **Автоматический поиск картинок** по названию (Wikimedia Commons)
- ✅ Можно вставить свою ссылку на изображение
- ✅ Умный список:
  - «Требуют внимания» — срок ≤ 30 дней
  - «Всё в порядке» — остальное
- ✅ Цветные статус-чипы (истёк / осталось N дней / дата)
- ✅ Поиск по названию и заметкам
- ✅ Уведомления за **30, 14, 7, 3, 1 день** и **в день истечения**
- ✅ Ежедневная проверка в 9:00 + восстановление после перезагрузки
- ✅ Современный Material 3 интерфейс
- ✅ Локальное хранение (Room) + кэш картинок (Coil)

## Как пользоваться

1. Нажмите **«Добавить»**
2. Введите название лекарства (например «Нурофен», «Аспирин», «Витамин D»)
3. Нажмите **«Найти картинку по названию»**
4. Выберите понравившуюся картинку из сетки
5. Укажите срок годности и сохраните

## Как собрать

1. Откройте папку `MedExpiry` в **Android Studio**
2. Дождитесь синхронизации Gradle
3. Запустите на устройстве или эмуляторе (Run ▶)

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Технологии

- Kotlin + Jetpack Compose + Material 3
- Room, WorkManager, Navigation
- Coil (картинки)
- Wikimedia Commons API (поиск изображений, без ключа)

## GitHub Actions — автоматическая сборка APK

При каждом push в `main` GitHub собирает APK.

### Скачать APK после сборки
1. Открой вкладку **Actions** в репозитории
2. Выбери последний успешный workflow **Build APK**
3. Внизу в **Artifacts** скачай `aptechka-debug-apk` или `aptechka-release-apk`

### Опубликовать Release с APK
1. **Releases → Create a new release**
2. Tag: например `v1.0.0`
3. Publish release
4. Actions соберёт APK и прикрепит к релизу автоматически

## Важно: корректное обновление установленной версии

- У новой версии должен быть тот же `applicationId` (`com.medexpiry.app`) и та же подпись (тот же keystore), что и у уже установленного приложения.
- При сборке релиза из тега `v1.1.7` Gradle автоматически выставляет `versionName=1.1.7` и увеличенный `versionCode`. Не меняйте `applicationId`.
- Чтобы обновление поверх старой версии работало, добавьте в GitHub → Settings → Secrets and variables → Actions секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Используйте именно исходный keystore, которым подписана установленная версия. Если исходного ключа нет, Android не позволит обновить приложение поверх старого — потребуется восстановить ключ или удалить старую установку (это удалит локальные данные приложения).
- Android обычно требует подтвердить установку в системном окне. Обычное приложение не может тихо заменить само себя без специальных системных/корпоративных прав. Нажмите «Обновить» в системном установщике.
- Создавайте новый тег для каждой версии, например `v1.1.7`, затем `v1.1.8`; не переиспользуйте старый тег.


## Исправление обновления поверх старой версии

Для обновления Android требует одинаковый `applicationId` (`com.medexpiry.app`), подпись тем же keystore и более высокий `versionCode`. Сборка из тега `v1.1.7` теперь получает `versionName=1.1.7` и автоматически увеличенный `versionCode`; следующая версия должна иметь новый тег, например `v1.1.8`.

**Настрой подпись в GitHub до публикации релиза:** открой Settings → Secrets and variables → Actions и добавь `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. `ANDROID_KEYSTORE_BASE64` — Base64-содержимое того же файла `app/keystore/aptechka.jks`, которым была подписана установленная версия. Получить строку в PowerShell можно командой `[Convert]::ToBase64String([IO.File]::ReadAllBytes('C:\путь\к\aptechka.jks'))`. Не публикуй сам ключ и пароли. Если исходный keystore потерян или отличается, Android не сможет обновить приложение поверх старого.

Android также обычно показывает системное подтверждение установки: приложение не может бесшумно установить обновление без специальных системных прав. В окне установщика нужно нажать «Обновить».
